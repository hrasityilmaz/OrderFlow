
# OrderFlow

Still **Under development**

A microservices architecture project built with **Spring Boot 4.2.0** and **Java 25**

The project aims to provide a modular, scalable, and maintainable architecture where each service operates independently and communicates with other services through well-defined interfaces.




## Technologies

- Java 25
- Spring Boot 4.2.0
- Spring Cloud Netflix Eureka
- Spring Security
- Spring Data JPA / Hibernate
- PostgreSQL
